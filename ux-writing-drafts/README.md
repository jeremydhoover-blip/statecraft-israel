# UX writing drafts

Drafts of three documents about the text the player reads in Statecraft: Israel. They are proposals for the maintainer to keep, change or drop. They are not part of the project and nothing in this folder is approved.

| File | What it is |
|---|---|
| [glossary.md](glossary.md), [glossary.yaml](glossary.yaml) | Terms in English and Hebrew: what the strings and content use today, a recommendation and who decides. The YAML is the source, the Markdown a readable view. |
| [ui-microcopy-guide.md](ui-microcopy-guide.md) | Rules for labels, buttons, refusals and errors, with real strings as examples and a review checklist. |
| [hebrew-localisation-guide.md](hebrew-localisation-guide.md) | Rules for the Hebrew strings. Every rule is marked as needing a native Hebrew reviewer. |

Every quoted string was checked against `upstream/main` at commit 50ba5d5c (15 October 2026). The drafts were written with AI help and checked by the author. The Hebrew has been read by a non-native reader and is not final.
